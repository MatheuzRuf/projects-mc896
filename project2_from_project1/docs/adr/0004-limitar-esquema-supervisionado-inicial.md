# Limitar o esquema supervisionado inicial

O primeiro benchmark aprenderá somente `HAS_CONDITION`, `HAS_FINDING`, `HAS_FACTOR`, `NEGATES`, `CAUSES` e `NO_RELATION`, porque são as distinções sustentadas pelo Medical Case Report Corpus. O documento origina um `ClinicalCase`, a entidade nativa `case` representa o `Patient`, e as relações nativas são mapeadas por tipo: `case HAS condition` para `HAS_CONDITION`, `case HAS finding` para `HAS_FINDING`, `case HAS factor` para `HAS_FACTOR`, `modifier MODIFIES finding` para `NEGATES` e `condition CAUSES finding` para `CAUSES`. Relações mais específicas do grafo, como tratamento, exame e severidade, permanecerão fora do classificador até existir evidência anotada compatível; mudar esse inventário posteriormente exigirá uma nova versão do esquema e novos resultados experimentais.
